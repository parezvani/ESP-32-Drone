How to register your drone

1
Navigate to your Dashboard via the top navigation bar.
2
Locate the registration area, enter a unique identifier for your quadcopter (e.g., drone_1), and click Register.
3
Copy the newly generated API Key immediately. Make sure to save it safely (like in a password manager), as it won't be displayed again.
💡
You will need this API key and your chosen drone name during Step 2 (Firmware Configuration) to link the telemetry endpoints properly.
Step 1 of 4

Flash GPS firmware

1
Navigate to the GPS firmware directory:
shell 
cd main/firmware/gps_telemetry
2
Open menuconfig and set the values below under FireFly GPS Broadcaster:
shell 
idf.py menuconfig
menuconfig — FireFly GPS Broadcaster
KeyValueNotes
Drone ID <your drone name> The name you registered in step 1
WiFi SSID <your network> 2.4 GHz only — ESP32-C3 does not support 5 GHz
WiFi Password <your password> Stored encrypted in NVS flash
Enable HTTPS POST to cloud y Required for the ground station to receive telemetry
API key for cloud endpoint <your API key> The key you copied in step 1
3
Save, exit menuconfig, then build and flash:
shell 
idf.py build flash monitor
📡
Watch the serial monitor for GPS fix acquired and POST 200. Your drone will appear on the map within a few seconds.

Set up the camera

1
In Arduino IDE open File → Examples → ESP32 → Camera → CameraWebServer. Set your WiFi credentials, select AI-Thinker ESP32-CAM as your board, and flash it. Open the Serial Monitor at 115200 baud — it will print the camera's IP address.
2
Confirm the stream is live in your browser:
url
http://<cam-ip>:81/stream
3
On your laptop, run the relay script to proxy the stream into the operator map:
shell 
python3 main/groundstation/cam_relay.py \
  --drone <your drone name> \
  --src   "http://<cam-ip>:81/stream" \
  --key   "<your API key>"
🎥
Once the relay is running, click Open camera on the map to see the live feed.

You're all set

✓
Your drone is registered and your firmware is configured. Head to the map — your drone should appear with a live badge once it has a GPS fix and is posting telemetry.
✓
To test fire detection, point the camera at a lighter or candle for a few seconds. The alert banner will pulse Fire detected and a bearing line will appear on the map.
✓
With two drones live, click Trigger triangulation on the map to compute a GPS fire coordinate from both bearing rays.
