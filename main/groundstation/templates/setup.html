01
Register your drone
Give your drone a name and get the API key that authorizes your ESP32 to send telemetry.
Lowercase letters, numbers, and underscores only — must match exactly what you enter in firmware menuconfig.
Drone registered — copy your API key now
—
⚠️ This key is shown exactly once. It's hashed in the database and cannot be recovered — save it in your password manager before continuing.
🔑
The same API key authorizes both your ESP32 GPS chip and your laptop's cam relay to POST data to this drone's row. Keep it secret.
Step 1 of 4
02
Flash GPS firmware
ESP32-C3 running ESP-IDF. Broadcasts GPS over UDP locally and HTTPS to the cloud.
1
Navigate to the firmware directory and open menuconfig:
shell 
cd main/firmware/gps_telemetry
idf.py menuconfig
2
Under FireFly GPS Broadcaster, enter these values. Your drone name and API key are pre-filled from step 1:
menuconfig — FireFly GPS Broadcaster
SettingValueNotes
Drone ID kenny_drone Must match what you registered exactly
WiFi SSID YourNetworkName 2.4 GHz only — ESP32-C3 doesn't support 5 GHz
WiFi Password •••••••• Stored in NVS, encrypted at rest
Enable HTTPS POST y Required for cloud telemetry
API key ff_live_… Paste the key you copied in step 1
3
Save, exit menuconfig, build, and flash:
shell 
idf.py build flash monitor
📡
The serial monitor prints GPS fix acquired and POST 200 when it's live. Your drone should appear on the map within a few seconds.
03
Flash ESP32-CAM
Stock Arduino CameraWebServer example — no custom firmware needed.
1
In Arduino IDE open File → Examples → ESP32 → Camera → CameraWebServer. Set your WiFi credentials in the sketch:
arduino (cpp) 
const char* ssid     = "YourNetworkName";
const char* password = "YourPassword";
2
Select AI-Thinker ESP32-CAM as your board, flash, then open Serial Monitor at 115200 baud to get the assigned IP address.
3
Confirm the stream is live in your browser at:
url
http://<cam-ip>:81/stream
4
Start the relay on your laptop. Your drone name and key are pre-filled — just replace <cam-ip>:
shell 
python3 main/groundstation/cam_relay.py \
  --drone kenny_drone \
  --src   "http://<cam-ip>:81/stream" \
  --key   "ff_live_…"
🎥
Once the relay is running the Open camera button on the map shows a live feed. The drone card gets a cam indicator.
04
Verify & launch
Confirm your drone is posting before going to the field.
1
Open the operator map. Your drone should appear within seconds of the ESP32 booting with a GPS fix — the panel shows live with a blinking green dot.
2
Check telemetry status right now:
Drone is live
No telemetry received yet
3
Test detection: point the camera at a lit candle from ~2 m. Within 2–3 seconds the alert banner should flip to Fire detected and a bearing line appears on the map.
🔺
Triangulation test: with two drones live and both detecting the same source, hit Trigger triangulation on the map. A fire pin appears at the computed GPS coordinate.
