About The Project

Catching fires before they spread

FireFly uses a coordinated fleet of ESP32-based drones to detect wildfires in areas where satellites are too slow and ground crews can't safely reach. The drones share GPS telemetry with a live ground station that pinpoints fire locations in real time.

Multi-drone bearing triangulation to geolocate fire sources with no fixed infrastructure
YOLOv8 computer vision running fire and smoke detection on live MJPEG streams
Real-time Leaflet map dashboard with drone trails, fire markers, and alert status
HTTPS cloud telemetry with Supabase authentication and per-drone API keys
Pipeline

How it works

From sensor to map pin in seconds. Each stage runs in parallel across the fleet.

01
Deploy Drones

ESP32-based drones broadcast GPS telemetry over UDP and optional HTTPS to the ground station every fix cycle.

02
Detect Fire

YOLOv8 processes live MJPEG camera frames, labeling smoke and fire with confidence scores. A 2–3 second sustained detection triggers an alert.

03
Triangulate

The Flask server intersects bearing rays from two or more drones using flat-earth geometry to produce a precise GPS coordinate for the fire.

04
Alert Operators

Fire pins and pulsing alerts appear on the live Leaflet map. Size, confidence, bearing, and source are all shown in real time.
