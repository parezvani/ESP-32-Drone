FIREFLY

Code Flow

From drone sensors to live fire map

Working demo path Firmware + camera + Python worker
Flask cloud API + browser dashboard
Field hardware Edge detection Cloud + operator
1

ESP32-C3 GPS Firmware

ESP-IDF C modules

  • read_pos_data.c: NMEA GPS over UART
  • ble_provision.c: Wi-Fi + API key from iOS
  • cloud_uplink.c: telemetry HTTPS uplink
2

ESP32-CAM Video Source

OV camera server

  • Streams MJPEG video over LAN at :81/stream
  • Provides live camera frames for fire detection
3

Python Edge Worker

OpenCV + YOLOv8 + triangulator

  • demo.py launches cloud + camera worker
  • demo_worker.py reads MJPEG frames
  • YOLOv8 detects fire/smoke after sustained presence
  • Bearing = pixel offset + drone heading + camera HFOV
  • Triangulates GPS fire point from two observations
4

Flask Ground Station / Cloud

API + database + live state

  • server.py receives telemetry, fires, frames
  • Stores drones, api_keys, telemetry, fires
  • Maintains live in-memory drone/fire state
  • Serves /api/state for dashboard polling
5

Operator Dashboard

Browser map UI

  • Map shows drones, camera preview, fire pins, alerts
  • Turns backend state into operator action cues
